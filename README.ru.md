# LocalTube — расширение Chrome

> English version: [README.md](README.md)

Репо для публичного продукта по скачиванию видео. Финальное название бренда пока не выбрано.

Архитектура намеренно разделена на две части:

```text
Интерфейс расширения Chrome
        ↓ Native Messaging
Локальный Windows-движок
        ↓
yt-dlp + FFmpeg/FFprobe
```

Расширение не разбирает и не скачивает подписанные `googlevideo`-потоки само. Оно отправляет текущий URL YouTube локальному движку, получает **реально доступные** качества и показывает пользователю только их.

---

## Текущий MVP

- Кнопка **«Скачать»** под обычными YouTube-видео;
- **Динамический список качеств** из `yt-dlp` — никаких фиксированных 4K/1080p/720p;
- Без накруток и апскейла;
- Раздельные метки: если доступен `1080p60`, показывается именно `1080p60`, а не просто `1080p`;
- Редактируемое имя выходного файла;
- Системный диалог **«Сохранить как»** Windows;
- Скачивание, склейка дорожек, конвертация в H.264/AAC при необходимости;
- Прогресс и отмена в реальном времени;
- Стабильный ID расширения для разработки;
- Одно активное скачивание за раз.

Shorts, плейлисты, живые трансляции, сайт и другие браузеры — на следующих этапах.

## Установка

### Способ 1: Инсталлятор (рекомендуемый)

Скачайте `LocalTube-Setup-*.exe` со страницы [Релизов](https://github.com/arzumanoff/LocalTube_Chrome-extension/releases/latest).

Установщик сам:
- Установит движок (yt-dlp + FFmpeg + Deno);
- Определит ваш видеоэнкодер (NVIDIA NVENC / AMD AMF / Intel QSV);
- Зарегистрирует Native Messaging host;
- Скопирует расширение в `%LOCALAPPDATA%\LocalTube\extension\`.

После установки откроется `chrome://extensions` — включите **Режим разработчика** и загрузите папку расширения.

### Способ 2: Ручная установка (для разработчиков)

Требуется: Python 3.12+, Git, Node.js 20+.

См. [`native-host/README.md`](native-host/README.md).

## Структура репозитория

```text
manifest.json
src/
  native-background.js     Координатор Native Messaging
  native-content.js        Кнопка на YouTube и диалог качеств
  core/native.js           Модель сообщений и качеств
native-host/
  host.py                  Процесс Native Messaging
  engine.py                Движок yt-dlp и FFmpeg
  protocol.py              Протокол с length-prefixed JSON
  build_host.ps1           Сборка под Windows
  install_host.ps1         Регистрация в Chrome (текущий пользователь)
  uninstall_host.ps1
tests/
  native.test.js
```

Файлы устаревшей browser-only реализации остались в истории Git, но активный манифест их больше не загружает.

## Проверка

### JavaScript-тесты

Node.js 20 или новее:

```bash
npm ci
npm test
npm run check
```

### Тесты Native Host

```bash
npm run test:host
```

### Ручной smoke-тест

```bash
npm run smoke:manual
```

Команда выводит пять обязательных ручных сценариев. Она не открывает диалоги сохранения автоматически и не скачивает видео в цикле.

## Правила продукта

- Показывать только те разрешения, которые **реально существуют** для текущего видео;
- Никогда не повышать разрешение (не апскейлить);
- Скрывать от обычных пользователей раздельные дорожки и детали кодеков;
- Сохранять итоговый файл как MP4 с H.264-видео и AAC-аудио;
- Не отправлять URL, куки, заголовки или медиаданные на сторонние серверы;
- Не обходить DRM, платный доступ, приватные видео, географические и аккаунтные ограничения.

Используйте продукт только для материалов, которые вы вправе сохранять.

# Бриф для сайта Media Downloader

> Документ для Kimi — содержит все факты, необходимые для создания лендинга и страницы загрузки.

---

## 1. Продукт

**Media Downloader** — бесплатное Chrome-расширение с открытым исходным кодом для скачивания видео с YouTube в MP4 (H.264/AAC).

Не требует регистрации, не отправляет данные на сторонние серверы, не содержит рекламы.

---

## 2. Целевая аудитория

Обычные пользователи, которые хотят сохранить YouTube-видео на компьютер в хорошем качестве без возни с командной строкой.

---

## 3. Ключевые возможности (текущий MVP)

- Кнопка **«Скачать»** под плеером YouTube
- **Реальные качества** — расширение показывает только те разрешения, которые действительно доступны для конкретного видео (360p, 720p, 1080p, 1080p60, 1440p, 4K…)
- Никакого навязывания фиксированного списка — если видео есть в 1080p60, вы увидите «1080p60»; если только в 30 fps — просто «1080p»
- Системный диалог **«Сохранить как»** — вы выбираете имя файла и папку
- Автоматическая конвертация в H.264/AAC MP4 (совместимость с любым плеером)
- Прогресс скачивания и возможность отмены
- Никакие URL, куки, заголовки видео не передаются наружу

---

## 4. Как это работает (простое объяснение)

Расширение не качает видео само. Оно передаёт ссылку на YouTube локальному движку на вашем компьютере, который через проверенные инструменты (`yt-dlp` + FFmpeg) скачивает видео и аудио раздельно, склеивает в MP4 и при необходимости перекодирует в H.264/AAC.

```
YouTube → Кнопка «Скачать» → Локальный движок → MP4-файл
```

Ни один байт видео не проходит через сторонний сервер.

## 8. Инструкция по установке (для сайта)

Сейчас это dev-установка — публичного инсталлятора ещё нет.

### Что нужно

Перед установкой убедитесь, что у вас есть:

| Инструмент | Где взять |
|-----------|----------|
| **Python 3.12+** | `python.org/downloads` |
| **FFmpeg + FFprobe** | `gyan.dev` (релизы для Windows) |
| **Deno** | `deno.com` (нужен для yt-dlp) |
| **yt-dlp** | `github.com/yt-dlp/yt-dlp` |

### Шаги установки

1. **Скачайте репозиторий** с GitHub (Code → Download ZIP)
2. **Соберите движок** — откройте PowerShell в папке `native-host`:
   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass
   .\build_host.ps1
   ```
3. **Положите инструменты** — скопируйте `ffmpeg.exe`, `ffprobe.exe` и `deno.exe` в папку `native-host/tools/`
4. **Установите движок**:
   ```powershell
   .\install_host.ps1
   ```
5. **Загрузите расширение** в Chrome:
   - Откройте `chrome://extensions`
   - Включите «Режим разработчика»
   - Нажмите «Загрузить распакованное расширение»
   - Выберите корневую папку проекта (где лежит `manifest.json`)
6. **Обновите вкладку YouTube** (Ctrl+F5) — кнопка «Скачать» появится под плеером

### Удаление
```powershell
.\uninstall_host.ps1
```

## 10. Дизайн-рекомендации

- **Тон:** дружелюбный, технически грамотный, без маркетинговых преувеличений
- **Цветовая гамма:** нейтральная, чистая — белый фон, тёмный текст, один акцентный цвет (например, синий или красный YouTube)
- **Язык:** русский (основной), возможно английская версия позже
- **Акцент на приватность** — значок замка, фраза «всё остаётся на вашем компьютере»
- **Никаких фейковых цифр** («10 000 скачиваний!») — проект новый, честность важнее
